The app now opens its full dashboard and pages inside the installed app. It no longer launches the website or requires ChatGPT login. The UI and Bengali fonts are bundled; local records work offline. All management data stays on this phone. Website synchronization, separate multi-user accounts, SMS and payments are not connected.

The dashboard prominently displays the full institution name in Bengali and English, with emerald/gold glass styling and animation.

Use Admin > Complete backup before uninstalling or changing phones. JSON backup restore, image/PDF selection and native print-to-PDF are supported. Existing APK installations can update with this release; native browser-based v1.0.3 stored no app records, and its website data is not imported automatically.

This preview APK uses the intentionally public preview signing key; use a confidential key for production distribution. Android 6+ and an up-to-date Android System WebView are required. External contact, map and social links require internet and their respective apps. No camera, contacts, SMS or storage runtime permissions are requested.
